### 2. Preload security: MET, no hole found (two minor caveats)
Read `ViewItemPreloadCache` (ViewItemProcessor.swift), `AppCoordinator.handleAuthEvent`/`showAuth`, `VaultCoordinator` preload call,
`VaultItemCoordinator` take.
- Late store: every step of the fetch re-checks `!run.isFinished && !Task.isCancelled && generation == startGeneration` on the MainActor;
  the check and `store` have no suspension in between. A fetch finishing after the 1 s timeout or after `clear()` stores nothing
  (also for a non-cancellable repository: `test_lateStoreAfterClear_nonCancellableFetch_isDropped`).
- Untaken entries: one expiry timer per entry (5 s), `take` also enforces the lifetime, `clear()` removes all and cancels timers.
- Window before routing: `handleAuthEvent` calls `clear()` before `router.handleAndRoute`, and `showAuth` clears again after the route
  is known. A preload started in between (generation current, vault still open) is cancelled and wiped by the second clear, so it
  cannot outlive the lock. The `.completeWithNeverUnlockKey` early return (autofill extension only) skips `showAuth` but the first clear already ran.
- Open after lock: `preload` returns `generation == startGeneration` evaluated after resumption; `VaultCoordinator` does not present when false;
  `take` after `clear` returns nil, so the view starts empty (`ViewItemState(toast:)`).
- Caveats (not holes): (a) a fetch that ignores cancellation keeps its decrypted value in task memory until it returns (at most the fetch
  duration, never stored in the cache, then released); (b) no test covers a preload that starts between the early clear and `showAuth`;
  it is covered by reading the code only.
- Tests (in the full Bitwarden-Unit run, xcresult): `PassYItemPreloadTests` 2/2, `PassYPreloadSecurityTests` 6/6, `AppCoordinatorTests` 50/50
  (incl. `test_handleAuthEvent_clearsPreloadBeforeRouting`, lock/logout/switch cancel tests), `VaultCoordinatorTests` 39/39
  (`..._clearedDuringPreload_doesNotPresent`), `ViewItemProcessorTests` 99/99, `VaultItemCoordinatorTests` 42/42, `PassYAppHygieneTests` 6/6.
